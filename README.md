Abhilash Guntuka — DevOps Portfolio
Run locally
```bash
npm install
npm run dev
```
Deploy to Vercel
Upload this project to a GitHub repository.
In Vercel, choose Add New → Project and import the repository.
Vercel will detect Vite automatically.
Build command: `npm run build`
Output directory: `dist`
Deploy.
Personalize
Replace `public/profile.jpg` with your preferred professional photo.
Update email, LinkedIn and GitHub URLs in `src/App.jsx`.
Update project descriptions and experience details in the arrays at the top of `src/App.jsx`.
